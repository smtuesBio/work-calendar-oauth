한국어

  • 사용자: 이 앱은 개발자 본인 한 명이 자기 컴퓨터에서 쓰는 개인 도구입니다. 다른 사용자에게 제공하지 않습니다.
  • 접근하는 데이터: 본인이 고른 Google 캘린더 하나의 일정(제목, 시작·종료 시각, 종일 여부, 메모, 취소 여부)과 본인 소유 캘린더 목록.
  • 사용 목적: 본인의 연구 업무 일정과 Google 캘린더를 양방향으로 맞추는 것뿐입니다.
  • 저장 위치: 일정과 인증 토큰은 사용자 컴퓨터의 로컬 파일에만 저장됩니다(토큰 파일은 본인만 읽을 수 있는 권한).
  • 제3자 제공: 어떤 데이터도 Google 이외의 서버나 제3자에게 보내거나 판매·공유하지 않습니다. 광고·분석 도구를 쓰지 않습니다.
  • Google API 데이터 사용: Google API에서 받은 정보의 사용과 전송은 Google API Services User Data Policy(Limited Use 요구사항 포함)를 따릅니다.
  • 삭제·권한 취소: Google 계정 → 서드파티 액세스에서 언제든 권한을 취소할 수 있고, 로컬 파일을 지우면 저장된 데이터가 모두 삭제됩니다.
  • 문의: github.com/smtuesBio

English

  • Users: This app is a personal tool used only by its developer on their own computer. It is not offered to other users.
  • Data accessed: events (title, start/end, all-day flag, notes, cancellation) on one Google Calendar the user selects, and the list of calendars the user owns.
  • Purpose: only to keep the user's research schedule and their Google Calendar in two-way sync.
  • Storage: events and authorization tokens are stored only in local files on the user's computer (token file readable by the user only).
  • Sharing: no data is sent, sold or shared with any server or third party other than Google. No advertising or analytics are used.
  • Google API data: use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
  • Deletion and revocation: access can be revoked at any time at Google Account → Third-party access; deleting the local files removes all stored data.
  • Contact: github.com/smtuesBio
