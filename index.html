BioPortal Work Calendar

개인 연구 일정 도구 · Personal research scheduling tool

BioPortal Work Calendar는 한 명의 연구자가 자신의 컴퓨터에서만 실행하는 개인 업무 캘린더입니다. 실험·논문 일정을 본인이 소유한 Google 캘린더 하나와 양방향으로 동기화합니다.

BioPortal Work Calendar is a single-user calendar that runs only on its owner's own computer. It synchronizes the owner's experiment and manuscript schedule with one Google Calendar that the owner owns.

사용하는 Google 권한 · Google access used

  • calendar.calendarlist.readonly — 본인 소유 캘린더 목록을 보여 주고 동기화할 캘린더 하나를 고르게 합니다. / Lists the owner's calendars so one can be selected.
  • calendar.events.owned — 선택한 캘린더의 일정을 읽고, 만들고, 고치고, 취소합니다. / Reads, creates, updates and cancels events on the selected calendar.
